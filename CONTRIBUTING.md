# Contributing to Tono

Thank you for your interest in Tono. Useful contributions include product feedback, clear bug reports, and documentation improvements.

## Share feedback or report a problem

- For LiuBai usage questions, check the [support page](https://tonomemo.com/liubai/support/).
- For product feedback or a reproducible problem, email [contact@tonomemo.com](mailto:contact@tonomemo.com). Include the product and version, what you expected, and what happened.
- For security vulnerabilities, follow the private reporting instructions in [SECURITY.md](SECURITY.md). Please do not post vulnerability details publicly.

Please do not include passwords, access tokens, private notes, or other sensitive personal information in reports.

## Code contributions

Contribution and licensing terms may differ by repository. Read the target repository's own CONTRIBUTING.md and license before opening a pull request. If the repository does not clearly invite code contributions or provide applicable terms, contact Tono before submitting code.
