# Contributing to Tono

Thanks for helping make Tono better. We welcome product feedback, reproducible bug reports, documentation fixes, and code contributions to the public Tono Site repository.

## Contribute to Tono Site

[Tono Site](https://github.com/tono-memo/site) is released under the [MIT License](https://github.com/tono-memo/site/blob/main/LICENSE). Pull requests for fixes and documentation improvements are welcome.

- For a larger change, open an issue first so we can discuss the approach.
- Keep pull requests focused and describe the user-facing change.
- Before opening a pull request, run the checks documented in the repository. For the website, run `pnpm build`.
- Include screenshots for visible website changes when useful.

## Product feedback and support

For LiuBai usage questions, start with the [support page](https://tonomemo.com/liubai/support/). Send product feedback or a reproducible issue to [contact@tonomemo.com](mailto:contact@tonomemo.com), including the product/version, expected result, and what happened.

LiuBai application source is not a public contribution target. Please send product feedback by email instead of opening code pull requests for that product.

## Security reports

Follow the private reporting instructions in [SECURITY.md](SECURITY.md). Do not post vulnerability details publicly.

Please do not include passwords, access tokens, private notes, or other sensitive personal information in reports.
